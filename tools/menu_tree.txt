# Illustrator menu tree.  Source of truth for the "menus" section of data/contexts.json.
#
# Format: one item per line, indent = 2 spaces per level.
#     Label | Shortcut | flags | description        (everything after Label is optional)
#   flags:  s = needs a selection      - = does NOT need one (Object/Effect default to "needs")
#   "Hide Edges|Show Edges" = the wording flips with app state; either alternative matches.
#   A line with children is a submenu; only leaf commands become nodes in contexts.json.
#
# Pre-filled from knowledge of Illustrator (Windows, 2024-2026). It is NOT verified against your
# copy: run  python tools/crawl_menus.py  to read the real menus, then
#                  python tools/build_contexts.py tools/menu_tree.crawled.txt
# (descriptions/flags you wrote here are kept when the crawl is merged in).
